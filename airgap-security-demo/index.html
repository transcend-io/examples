Transcend Airgap security demo

See what Transcend Airgap (airgap.js) stops in the browser. The same five story steps run in four modes. Each page also has an Attack replay button.

  • off: no Airgap. Every step succeeds.
  • report-only: Airgap watches and blocks nothing.
  • block: unknown hosts are blocked, with the generated Content Security Policy.
  • navigation: block plus navigation control.
